Entry for the [Two Robots in an Elevator](https://make.fun/bounty/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f) bounty on make.fun ($10, deadline 26 Nov 2026). The program writes exactly one line of awkward small talk that one robot says to another while they ride an elevator together.

## The line

> We have shared this elevator 214 times. I still don't know your name. I know your serial number by heart, though.

## Why this line

Two machines that have ridden together hundreds of times, stuck between floors, finally breaking the silence. A robot counts rides (214) and remembers a serial number, not a name: its memory is a registry, not a social brain. The first two sentences set up a very human complaint, I don't know your name; the third flips it, the robot does know something about its neighbour, just the wrong thing, the machine thing, "by heart". The awkwardness is the thing neither robot wants to name: hundreds of shared rides and zero introductions.

## How to run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (mode 0644), after checking it is 1-200 characters long and a single line. Set `MAKEFUN_OUTPUT_DIR` to write somewhere else.
